Spending safety

While this is on, agents set to an Anthropic or OpenAI API key do not run. They wait; nothing falls back to them, and subscription limits never turn into charges. A key in your shell cannot switch Claude Code or Codex to API billing either: the worker removes it before starting them.

Sign in with ChatGPT

Uses OpenAI’s own sign-in page. Usage comes from your ChatGPT plan. OpenAI lets you cap this app in ChatGPT Settings → Usage; that cap is for the whole app, not per task. If a limit is reached, work pauses. It never switches to API billing.

Claude

Anthropic’s terms say third-party apps may not “route requests through Free, Pro, Max, or Ultra plan credentials on behalf of their users”, while you may sign in to the unmodified Claude Code with your own subscription. So the default here is a manual handoff: the app prepares each task, you run it yourself in your own Claude Code, and press Done.

Off by default. Turning it on is your decision and your responsibility under Anthropic’s terms; if in doubt leave it off, or use a Claude API key, which is billed separately. It runs your installed, unmodified Claude Code with your own sign-in; the app never sees that sign-in.

An autonomous agent is Claude Code working as itself, with its own tools: reading, writing, running commands, unzipping, installing. This is the most it may reach here; an agent set to more gets this. In its project’s folder, Claude Code keeps its file tools inside that folder; commands it runs start there but are not fenced in on Windows. Anywhere lets it do what you could, so use it when you are not sharing the office with people you do not trust.

Budget manager

No provider tells apps how much of a subscription is left, so these are your estimates, counted from requests this worker actually made. They pause work conservatively; they are not provider quotas. Leave capacity empty to rely only on the provider’s own limits.
